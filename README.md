# Чисельне розв'язування нелінійних рівнянь

Програмне забезпечення з графічним інтерфейсом (GUI) для наближеного розв'язання нелінійних рівнянь за допомогою чисельних методів. Проєкт реалізовано мовою Python із використанням бібліотек `tkinter` та `matplotlib`.

---

## 🛠 Основний функціонал
* **Чисельні методи:**
  * Метод дихотомії (поділу навпіл)
  * Метод простих ітерацій
  * Метод Ньютона (дотичних) із чисельним диференціюванням
* **Гнучке введення даних:**
  * Вибір стандартних варіантів завдань із методички.
  * Можливість введення **власного довільного рівняння** з клавіатури за допомогою безпечного парсингу (`eval`).
  * Налаштування меж відрізка $[a, b]$ та довільної похибки ($\varepsilon$).
* **Таблиця результатів (Treeview):** Накопичення та виведення результатів (похибка, кількість ітерацій, знайдений корінь, значення функції в точці).
* **Візуалізація:** Побудова графіків досліджуваних функцій на заданому відрізку за допомогою `matplotlib`.
* **Експорт даних:** Можливість збереження результатів розрахунку у текстовий файл (`.txt` / `.csv`).
* **Локалізація:** Повна підтримка української мови інтерфейсу.
* **Валідація:** Перевірка області визначення (наприклад, для логарифмів) та коректності меж.

## 📁 Структура проєкту
Проєкт має модульну архітектуру:
```text
├── lang/
│   └── lang_ua.py          # Словник локалізації (українська мова)
├── numerical_methods/
│   ├── dichotomy.py        # Реалізація методу дихотомії
│   ├── iteration.py        # Реалізація методу простих ітерацій
│   └── newton.py           # Реалізація методу Ньютона
├── NL-Solver.exe           # Виконуваний файл
├── functions.py            # Набір функцій для варіантів та чисельного диференціювання
├── validators.py           # Модуль перевірки меж та області визначення
├── export_utils.py         # Модуль збереження у файл та побудови графіків
├── main.py                 # Головний файл запуску GUI-додатка
└── feather_2.ico           # Піктограма програми
