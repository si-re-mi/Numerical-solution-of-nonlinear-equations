==================================================
ІНСТРУКЦІЯ З ВСТАНОВЛЕННЯ ТА ЗАПУСКУ ПРОЄКТУ
==================================================

1. ВИМОГИ ДО СИСТЕМИ
--------------------
На комп'ютері має бути встановлений Python версії 3.10 або вище.
Завантажити можна з офіційного сайту: https://www.python.org/downloads/
(Під час встановлення обов'язково поставте галочку "Add Python to PATH").

2. ВСТАНОВЛЕННЯ НЕОБХІДНИХ БІБЛІОТЕК
-----------------------------------
Для повноцінної роботи програми (побудова графіків та робота інтерфейсу) 
необхідно встановити сторонні бібліотеки `matplotlib` та `numpy`.

Відкрийте командний рядок (Terminal / Command Prompt / PowerShell) 
у папці з проєктом та виконайте команду:

    pip install matplotlib numpy

*(Примітка: модулі `tkinter` та `math` входять до стандартної бібліотеки Python)*

3. ЗАПУСК ПРОГРАМИ
------------------
Після успішного встановлення залежностей виконайте в терміналі команду:

    python main.py

4. ШВИДКИЙ ЗАПУСК (БЕЗ ВСТАНОВЛЕННЯ PYTHON)
----------------------------------------
Якщо ви хочете запустити програму на комп'ютері, де не встановлено Python, 
ви можете скористатися вже готовим виконуваним файлом:
Запустіть файл:
    NL-Solver.exe

Програма відкриє графічне вікно з усіма елементами керування, таблицею 
результатів та підтримкою локалізації.
